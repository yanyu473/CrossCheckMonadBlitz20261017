CrossCheck：双模型审阅报告、Monad 测试网存证和浏览器独立复核。

这份公开演示是什么

公开页面回放三份真实调用产物。样例报告已经真实写入 Monad 测试网，浏览器可以直接读取 RPC 并核对完整报告指纹。修改模型理由后，核验会失败。

三份样例分别覆盖"两家一致认为成立""两家判断分歧""两家都拒绝判断"三种结局，理由为模型原始返回、未做任何改写。需要说明的是，两个评审方共用同一家上游网关，因此它提供的是同一关口下两份模型意见的独立记录，不具备两家厂商各自签名的可信度；核验通过也只证明报告确被签发且未被改动，不证明判断本身正确。

完整产品包含什么

四页前端、Express 后端、并行模型适配器、SSE 进度、持久报告、授权发证合约、完整 JSON 导出及浏览器复核。真实 API 模式已跑通：两份判断分别由 gpt-6-sol 与 claude-opus-5-5 经同一中转网关并行返回，理由原样写入报告，三条公开样例即其中三次真实调用的产物。

为什么有完整报告指纹

报告包含原文、请求与返回模型标识、两份判断、理由、时间及规则版本。对象键递归排序，数组保序，原文不去空白；模型理由也参与 Keccak-256。指定合约只接受授权发证钱包，浏览器核对交易回执、事件、发证地址和指纹。

如何复查

回到演示页，选择样例，点击核验原始报告。确认成功后，再点击修改模型理由并核验。也可以下载 JSON，在自己的浏览器导入。导入文件仅本地处理，不上传。
